## Format Rules (for agent reference — DO NOT include in output)

### Scoring Rubric
| Score | Emoji | Meaning |
|---|---|---|
| 9-10 | 🔴 | MEGA — Dominating feeds |
| 7-8 | 🟠 | HIGH — Trending actively |
| 5-6 | 🟡 | MODERATE — Solid interest |
| 3-4 | 🟢 | LOW — Niche interest |
| 1-2 | ⚪ | MINIMAL — Routine update |

### Language Rules
1. **Titles**: Keep in English (preserves searchability)
2. **Summaries**: Vietnamese, 2-3 sentences max
3. **Tags**: English, lowercase, backtick-wrapped
4. **Content Picks**: Vietnamese (except platform names)

### Content Scope Rules
1. **ONLY AI/Tech/Dev/Funding** — No pure geopolitics, natural disasters, or sports
2. Exception: Include geopolitical/world events ONLY if they directly impact tech (e.g., "US sanctions on chip exports" = YES, "Venezuela earthquake" = NO)
3. Deduplicate: same story in multiple categories → keep in most relevant one only

### Item Length Rules
1. Each item summary: **2-3 sentences maximum**
2. No paragraph walls — readers scan, not read
3. Metadata lines (Pricing, Link, Source) are separate lines, not inline
