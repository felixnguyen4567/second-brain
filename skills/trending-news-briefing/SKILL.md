# Trending News Briefing v1.0

> **Purpose**: One-command daily briefing across 4 verticals — World News, Technology, AI, Investment — pulling from the most reputable sources on the internet.

## Invocation

This skill is triggered when the user asks for a daily news briefing, trending news report, or uses the phrase "trending news briefing". Run this skill exactly as documented below.

## Output Specification

The final report MUST be saved as a Markdown file at:
```
{workspace}/output/YYYY-MM-DD-trending-briefing.md
```

The report MUST contain exactly **4 sections**, each with exactly **5 items**, for a total of **20 news items**.

## Execution Process

### Phase 1: Research (Parallel Web Searches)

Execute the following 4 `search_web` calls **in parallel** to maximize speed. Use today's date in the queries to ensure freshness.

```yaml
Search 1 - World News:
  query: "top world news today {YYYY-MM-DD} breaking headlines"
  
Search 2 - Technology:
  query: "top technology news today {YYYY-MM-DD} trending tech"

Search 3 - AI:  
  query: "artificial intelligence AI news today {YYYY-MM-DD} latest developments"

Search 4 - Investment:
  query: "stock market investment news today {YYYY-MM-DD} trading crypto finance"
```

### Phase 2: Deep Dive (Conditional)

If any category from Phase 1 returned fewer than 5 distinct, high-quality stories, run a **second wave** of targeted searches:

```yaml
Fallback Sources (search_web with domain hint):
  World News:
    - domain: reuters.com
    - domain: apnews.com
    - domain: bbc.com
  Technology:
    - domain: theverge.com
    - domain: techcrunch.com
    - domain: arstechnica.com
  AI:
    - domain: venturebeat.com
    - domain: huggingface.co
    - domain: arxiv.org
  Investment:
    - domain: bloomberg.com
    - domain: cnbc.com
    - domain: coindesk.com
```

### Phase 3: Evaluate & Score

For each of the 20 items collected, assign a **Virality Score (1-10)** based on the following weighted criteria:

```yaml
Virality Scoring Rubric:
  Controversy / Debate Potential:  25%  # Does it spark strong opinions?
  Novelty / First-of-its-kind:    25%  # Is this genuinely new?
  Impact Scale:                   20%  # How many people does it affect?
  Emotional Trigger:              15%  # Does it provoke fear, excitement, or outrage?
  Shareability / Meme Potential:  15%  # Would people share this on social media?

Score Interpretation:
  9-10: 🔴 MEGA VIRAL — Dominating feeds, everyone is talking about it
  7-8:  🟠 HIGH VIRAL — Trending actively, strong engagement potential
  5-6:  🟡 MODERATE — Newsworthy, solid interest but not explosive
  3-4:  🟢 LOW — Niche interest, limited viral spread
  1-2:  ⚪ MINIMAL — Routine update, minimal engagement expected
```

## Rules & Constraints

1. **Summaries MUST be in Vietnamese** — This makes it immediately actionable for the user.
2. **Titles can remain in English** — Preserving original titles for searchability.
3. **Virality scores must use the rubric** — No arbitrary numbers. Each score should be justifiable.
4. **Stories must be from the last 24 hours** — No recycled or older news. If a story is older than 48h, exclude it.
5. **Deduplicate aggressively** — The same story appearing in multiple sources counts as ONE item. Pick the best source.
6. **Sort by virality within each category** — Highest virality score = #1 position.
7. **Always include the "Content Opportunities" section** — This bridges the briefing to the user's content production workflow.
8. **No paywalled content** — If a story is behind a paywall, find an alternative free source or summarize from metadata.

## Source Credibility Tiers

```yaml
Tier 1 (Highest Trust — Prioritize):
  World: Reuters, AP News, BBC, Al Jazeera, The Guardian
  Tech: The Verge, Ars Technica, TechCrunch, Wired
  AI: VentureBeat AI, Hugging Face, arXiv, MIT Tech Review
  Finance: Bloomberg, Reuters Finance, CNBC, Financial Times

Tier 2 (Good — Use as supplements):
  World: CNN, NPR, Politico, Foreign Policy
  Tech: Engadget, ZDNet, The Register, Hacker News
  AI: MarkTechPost, AI News, Analytics India Magazine
  Finance: Yahoo Finance, Seeking Alpha, CoinDesk, The Block

Tier 3 (Use with caution — Verify claims):
  All: Social media posts, blog posts, X/Twitter threads
  Note: Can be used for "pulse" and trending signals, but claims must be verified against Tier 1/2 sources
```

## Error Handling

| Scenario | Action |
|---|---|
| A category returns < 5 stories | Run fallback search. If still < 5, fill with best available and note "[Limited coverage today]" |
| Search returns no results | Skip to fallback domains. If all fail, note "[Unable to retrieve — check manually]" |
| Duplicate story across categories | Keep in the MORE relevant category only. Find a replacement for the other category |
| All searches fail | Generate a minimal report explaining the failure and suggest manual sources to check |
