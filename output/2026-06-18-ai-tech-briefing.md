## 💡 AI TIPS & WORKFLOWS

### Tip 1: Nadella's "Token Capital" Framework — Cách giữ lợi thế cạnh tranh trong kỷ nguyên AI
Satya Nadella vừa chia sẻ framework cực hay cho doanh nghiệp:
- **Human Capital**: Kiến thức, phán đoán, mối quan hệ của team bạn
- **Token Capital**: AI capabilities mà CÔNG TY BẠN tự xây và sở hữu
- **Learning Loops**: Hệ thống capture mọi interaction, correction → feed lại vào model riêng
- **Pro tip**: Phải có khả năng swap base model (GPT → Claude → Gemini) BẤT CỨ LÚC NÀO mà không mất institutional knowledge. Nếu không — bạn là "dumb data pipe".

### Tip 2: Headroom — Cắt giảm chi phí API AI ngay lập tức
Token costs đang ăn mòn margin? Headroom giúp:
1. Nén context trước khi gửi vào LLM (giảm 60-95% tokens)
2. Giữ nguyên semantic quality
3. Tích hợp dễ dàng vào pipeline hiện có

```bash
# Install
npm install -g headroom-cli

# Compress trước khi gửi vào LLM
headroom compress --input ./data --output ./compressed --ratio 0.3
```

### Tip 3: Agent Discovery — Agentic Resource Discovery (ARD)
GitHub vừa launch ARD specification + Agent Finder cho Copilot. Cách agents tự discover tools:
1. **ARD Spec**: Chuẩn mở cho agent tự tìm capabilities cần thiết
2. **Agent Finder**: Copilot tự phát hiện tools/MCP servers phù hợp với task
3. **Ecosystem play**: Kết hợp MCP (connect tools) + ARD (discover tools) = agent tự trị thực sự
