## 💡 AI TIPS & WORKFLOWS

### Tip 1: "Spec-First" Pattern — Tạo CLAUDE.md trước khi code
Thay vì nhảy thẳng vào code, developer pro 2026 tạo file `CLAUDE.md` hoặc `spec.md` trong repo — đóng vai "hiến pháp" cho AI agent. File này chứa: coding conventions, architecture decisions, testing strategies. Agent đọc file này trước mỗi task → output nhất quán, ít lỗi hơn.

**Cách làm:**
```markdown
# CLAUDE.md
## Architecture
- Next.js 16 App Router, TypeScript strict
- Supabase for auth + database
## Testing
- Vitest for unit tests, Playwright for E2E
## Style
- Use Tailwind 4, no inline styles
- Vietnamese comments, English code
```

### Tip 2: "Pressure Valve" Strategy — Tiết kiệm chi phí AI billing
GitHub Copilot chuyển sang usage-based billing tháng 6/2026 → chi phí tăng vọt. Chiến lược:
- **Task phức tạp** (architecture, debugging): Dùng model mạnh (Claude Opus 4.8, GPT-5.5)
- **Task đơn giản** (summarize PR, triage bug, docs): Chạy local model qua Ollama (Phi-4 14B)
- Tiết kiệm 40-60% chi phí mà không giảm chất lượng output quan trọng.

### Tip 3: Headroom — Nén context trước khi gửi LLM
Install `headroom` và chạy trước mọi LLM call. Nén tool outputs, logs, RAG chunks 60-95%. Ví dụ: 1 file log 50K tokens → nén còn 5K tokens mà giữ nguyên thông tin quan trọng. Tiết kiệm $$$  trên mỗi API call.
