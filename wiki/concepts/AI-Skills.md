# AI Skills

Reusable instruction sets that let AI assistants follow your standards — brand colors, formatting, workflows — without prompting repetition.

## How Skills Work

1. Enable Skills in settings (Settings → Capabilities → Turn on Skills)
2. Create or install skills (upload .zip or .md file)
3. Claude auto-selects relevant skills or you explicitly direct
4. Skills apply automatically to matching requests

## Claude Skills Ecosystem

Built-in skill creator generates skills from conversation context — no code required.

### Top 11 Claude Skills (Tested by The PyCoach)

#### Presentations & Visuals
1. **Slide Deck Builder** — Rough idea → full slide sequence with visual style
2. **Explainer Graphic** — Concept → HTML visual explainer with analogies

#### Marketing & Business
3. **Branded Carousel Generator** — Content → branded social carousel
4. **Brand Applicator** — Document + brand rules → polished output
5. **Market Competitors** — Website → competitive intelligence report
6. **Workflow Visualizer** — Process → interactive visual map
7. **Contract Reviewer** — Contract → key terms, red flags, yellow flags
8. **Decision Council** — Decision → multi-expert synthesis with next steps
9. **Quick Research** — Topic → structured brief (summary, features, pros/cons, pricing)

#### Frontend Development
10. **Frontend Design** — Official Claude Code skill for production-ready UI
11. **Implement Design** — Figma → code with high visual fidelity

## Skills vs Simple Prompting

| Aspect | Prompting | Skills |
|--------|-----------|--------|
| Reuse | Repeat each time | Automatic |
| Consistency | Variable | Consistent |
| Maintenance | None | Update once |
| Learning Curve | Low | Medium |
