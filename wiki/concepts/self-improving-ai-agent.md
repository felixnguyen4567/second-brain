# Self-Improving AI Agent

An AI agent that gets more capable over time through actual use — not through configuration updates, but through continuous learning from interactions.

## Core Mechanism

1. **Observe** → remember what happened
2. **Extract** → identify what worked
3. **Codify** → write as reusable skill
4. **Apply** → load in similar future situations

## Key Challenge

Avoid token bill growth as the agent learns more → requires cache-aware memory architecture.
