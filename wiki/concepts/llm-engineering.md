# LLM Engineering

Building applications with large language models — the engineering discipline of connecting foundation models to real products. Distinct from ML research; focuses on practical questions: RAG architecture, evaluation frameworks, deployment tradeoffs, prompt design, fine-tuning decisions.

## Key Questions

- When to fine-tune vs. use foundation models?
- How to build reliable RAG pipelines?
- How to evaluate non-deterministic, multi-step systems?
- How to reduce hallucination in production?
- How to optimize for cost and latency?
