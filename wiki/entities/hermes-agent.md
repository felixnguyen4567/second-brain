# Hermes Agent

Open-source AI agent built by [Nous Research](https://nousresearch.com/).

## Key Characteristics

- **Single agent** architecture (vs OpenClaw's multi-agent orchestration)
- **Self-improving**: gets more capable the longer it runs through actual use, not config updates
- **Skill-based learning**: extracts successful patterns into reusable skills
- **Cache-aware memory**: avoids growing token bills as it learns

## Core Innovation

Hermes bridges the gap between "storing what happened" and "storing what worked" — it goes beyond recall to extraction and application.
