# Claude

Claude is Anthropic's flagship AI assistant, supporting extensible **Skills** — reusable instruction sets that let Claude follow brand guidelines, domain standards, and custom workflows without prompting repetition.

## Key Capabilities

- **Skills System:** Create or install reusable instruction sets for consistent outputs
- **Skill Creator:** Built-in tool that generates skills from conversation context — no code required
- **Dual-use:** Claude auto-selects relevant skills from installed set or can be explicitly directed
