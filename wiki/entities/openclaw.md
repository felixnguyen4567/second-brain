# OpenClaw

**OpenClaw** là một open-source personal AI assistant framework (nickname: "Lobster"). Đây chính là hệ thống mà July đang chạy phục vụ cho Bear.

## Overview

- **Website:** https://openclaw.ai
- **GitHub:** https://github.com/openclaw (35 repositories)
- **Current version:** Check via `openclaw --version`
- **Platform:** Self-hosted, cross-platform (Mac, Linux, Windows)

## Key Capabilities

- Connects LLMs to files, browsers, messaging (Telegram, WhatsApp, Slack, Discord)
- Persistent identity and memory across sessions
- Skills system for extensible functionality
- Multi-agent orchestration (agentic AI)
- Tool use and automation

## Architecture

- **Gateway:** Core always-on process running on server
- **Agent:** AI brain powered by LLM (currently MiniMax-M2.7)
- **Channels:** Telegram, WhatsApp, Slack, Discord integration
- **Skills:** Extensible instruction sets
- **Memory:** Persistent context and wiki system
